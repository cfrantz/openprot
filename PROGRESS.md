# TPM Integration Progress Report

## Accomplishments

### 1. Experimental Platform Layer (`services/tpm/src/platform`)
- Implemented `TpmClock` using Earlgrey's `mtime` register with target-specific tick rates (Verilator, FPGA, Silicon).
- Implemented `TpmNv` using an 8KB RAM-backed buffer for experimental persistence.
- Implemented `TpmLifecycle` to handle power-on, reset, and the critical `was_power_lost` state.
- Ensured the layer is `no_std` compatible and uses `RefCell` with a `Sync` wrapper instead of atomics, as Earlgrey lacks the 'A' extension.

### 2. TCGTPM Rust Library Modernization
- **`tpm_types`**: Converted to `#![no_std]`, removed `anyhow`, `log`, and `rand_core` dependencies to eliminate `std` requirements.
- **`nullcrypto`**: Converted to `#![no_std]`, fixed missing imports (`Option`, `Into`, `Ord`) required by the TPM crypto macros.
- Updated `TCGTPM/MODULE.bazel` and `BUILD.bazel` files to support cross-workspace dependencies and `no_std` compilation.

### 3. Two-Process Architecture
- **`tpm_service` (`services/tpm`)**: Created a standalone service that acts as a `channel_handler`. It initializes the TCG-TPM C core via FFI and enters an IPC loop to dispatch commands.
- **`usb_tpm_bridge` (`protocol/usb/usbtpm`)**: Created a USB gateway that acts as a `channel_initiator`. It implements the `UsbClass` and forwards command payloads to the `tpm_service` via `syscall::channel_transact`.
- **System Integration**: Created `target/earlgrey/tests/usbtpm` with `system.json5` and `target.rs` to bootstrap the two-process system via the Maize kernel.

## Current Technical State
- The Rust components (`tpm_platform`, `tpm_service` binary, `usb_tpm_bridge` binary) build successfully for the `earlgrey` target.
- The `tpm_core` C library (local copy of `simulator_impl`) is configured to use `SYM_LIB=Rust` and `HASH_LIB=Rust` via `defines` in `TCGTPM/TPMCmd/tpm/include/private/BUILD.bazel`.

## Current Blocker
The build currently fails during C compilation because the TCG-TPM core expects bridge headers for the selected crypto library. When `SYM_LIB=Rust`, the code attempts to `#include "Rust/TpmToRustSym.h"`, which does not yet exist.

## Next Steps
1. **Create Rust Bridge Headers**: Implement the following headers in `TCGTPM/TPMCmd/tpm/cryptolibs/Rust`:
   - `TpmToRustSym.h`: Map symmetric calls to Rust `CryptSymmetric*` functions.
   - `TpmToRustHash.h`: Map hash calls to Rust `CryptHash*` functions.
   - `TpmToRustMath.h`: Map math calls to Rust `CryptMath*` functions.
2. **Update Build Rules**: Ensure the new `Rust` cryptolib headers are included in the `tpm_core` search path.
3. **Verify Linking**: Confirm that the `#[no_mangle]` symbols generated by the Rust macros are correctly resolved by the C linker.
4. **Final System Build**: Execute `bazel build //target/earlgrey/tests/usbtpm:usbtpm`.
